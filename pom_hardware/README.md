# pom_hardware

## 1) Overview

`pom_hardware` provides the live `ros2_control` hardware plugins for POM mobile bases.

It specializes the generic `2FWS2RWD` and `2FWS4WD` hardware abstractions from `romea_mobile_base_hardware` and connects them to the POM low-level ROS1 interface through `pom_bridge`.

The exported plugins are:

| Plugin | Base class | Mobile base architecture |
|---|---|---|
| `pom_hardware/PomHardware2FWS2RWD` | `HardwareSystemInterface<HardwareInterface2FWS2RWD>` | `2FWS2RWD` |
| `pom_hardware/PomHardware2FWS4WD` | `HardwareSystemInterface<HardwareInterface2FWS4WD>` | `2FWS4WD` |

## 2) Hardware concept

`PomHardware` is loaded by `controller_manager` from the `<ros2_control>` description generated by `pom_description`.

At runtime, it:

1. reads the POM `ros2_control` hardware information;
2. creates the architecture-specific command and state interface mapping;
3. loads the wheel geometry used to convert wheel commands and feedback;
4. receives wheel joint feedback from the bridge as `sensor_msgs/msg/JointState`;
5. converts controller commands into `ackermann_msgs/msg/AckermannDrive`;
6. publishes the Ackermann command to the bridge;
7. converts bridge joint feedback into `ros2_control` state interfaces.

From the controller point of view, this behaves like a standard mobile base hardware plugin: `MobileBaseController2FWS2RWD` or `MobileBaseController2FWS4WD` writes front wheel steering and wheel speed commands, then reads joint feedback from state interfaces to compute odometry.

## 3) Bridge topics

The hardware plugin does not communicate directly with the POM low-level controller. It exchanges commands and feedback with `pom_bridge`.

The topics are derived from the `ros2_control` hardware name. With the usual `pom_base` hardware name, the topics are:

| Topic | Direction | Message |
|---|---|---|
| `/pom/base/bridge/vehicle_controller/cmd_steer` | published by the hardware plugin | `ackermann_msgs/msg/AckermannDrive` |
| `/pom/base/bridge/vehicle_controller/joint_states` | subscribed by the hardware plugin | `sensor_msgs/msg/JointState` |

`PomHardware` converts the left and right front steering commands into a single Ackermann steering angle using the two-wheel steering kinematic model. For the `4x4` variant, front and rear wheel speed commands are reduced to the longitudinal speed expected by the bridge.

## 4) Relation with other packages

`pom_hardware` is the live hardware specialization of the POM mobile bases:

* `pom_description` selects the matching `pom_hardware` plugin in `live` mode;
* `romea_mobile_base_hardware` provides the reusable `2FWS2RWD` and `2FWS4WD` hardware abstractions;
* `romea_mobile_base_utils` provides helpers used to read `hardware_interface::HardwareInfo`;
* `romea_mobile_base_controllers` sends commands through the exported `ros2_control` interfaces;
* `pom_bridge` connects the ROS2 hardware plugin to the POM ROS1 low-level interface;
* `pom_bringup` starts the controller manager and loads this hardware plugin in live mode.
